A full-stack web application built with Python and Flask to help users track and manage their job applications in one place.
Features

1.Add, edit, and delete job applications
2.Dashboard with summary cards (Applied, Interview, Offer, Rejected)
3.Bar chart visualization using Chart.js
4.Search by company name
5.Filter by application status
6.Deadline warnings with visual indicators
7.Color-coded status badges
8.Flash messages for success and error feedback
9.Responsive design with Bootstrap 5
